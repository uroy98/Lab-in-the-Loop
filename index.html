Why you would want this

You are about to let a model choose reaction conditions for you. A model is only worth using if you know when to believe it — and every check costs bench time.
18couplings the model has already scored. It has produced a predicted yield for every one. Running them all to check is weeks of bench time and material.
?but which predictions can you trust? From the outside a confident wrong answer looks exactly like a confident right one. Nothing in the prediction tells you.
2reactions at a time. So the system chooses a pair, the bench answers, the model updates, and it chooses again — spending as little lab time as possible working out where it breaks.

Choose how the system decides what to run next

Nobody picks the reactions. The system scores everything it has not tried yet, runs the two that score highest, learns from the results, and repeats — 9 times over, 18 reactions in all. The only thing you choose is the rule it scores by.

What you are looking at

Every yield the lab returns here was measured by a chemist, not simulated — this replays reactions from ACS Catalysis 2025, 15, 14207–14214 so a campaign can be run in seconds. The model itself is real and untouched: it was trained on 198 literature reactions and has never seen any of these 28 measurements. Notice that retraining helps some reactions and hurts others — a single experiment shifts the model's whole picture of the chemistry, and whether that shift is worth having depends entirely on which reaction you chose to run.

Which is the problem this tab cannot solve. Here you find out whether an experiment was worth doing only after it has been done — the bench time is already spent. A real lab gets a fixed budget of experiments and has to choose well in advance. Autonomous experimentation is that missing piece: you stop picking reactions, and the system picks them for itself — either chasing the highest predicted yield, picking at random, or targeting the reactions it is least sure about.
